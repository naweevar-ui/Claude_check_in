# เว็บเช็คชื่อคลาส Claude AI

**เวอร์ชัน 1.4.2** · อัปเดต 14 พ.ย. 2569 · ดูประวัติการเปลี่ยนแปลงใน [CHANGELOG.md](CHANGELOG.md)

เว็บเช็คชื่อโทนฟ้า-ชมพูพาสเทล ผู้เข้าเรียนกดชื่อตัวเอง เซ็นลายเซ็น ระบบบันทึกเวลาเช็คอินและบอกว่าตรงเวลาหรือสาย แล้ว **บันทึกลง Google Sheets อัตโนมัติ** ใช้ได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์

## โครงสร้างไฟล์

```
claude-checkin/
├── index.html                  หน้าเว็บทั้งหมด (HTML + CSS + JavaScript ในไฟล์เดียว)
├── config.js                   ตั้งค่า: ลิงก์ Google Apps Script ฯลฯ  ← แก้ไฟล์นี้ไฟล์เดียว
├── apps-script/
│   ├── Code.gs                 โค้ดหลังบ้านบน Google Apps Script (บันทึกลง Google Sheets)
│   └── appsscript.json         ค่าตั้งของโปรเจกต์ Apps Script (ใช้กับ clasp ได้)
├── templates/
│   └── attendees-template.csv  แม่แบบไฟล์รายชื่อ
├── private/                    ไฟล์รายชื่อจริง (อยู่ใน .gitignore จะไม่ขึ้น GitHub)
├── CHANGELOG.md                ประวัติเวอร์ชัน
├── .nojekyll                   ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ
└── .gitignore
```

## ขั้นที่ 1 — สร้าง Google Sheet และหลังบ้าน (ประมาณ 5 นาที)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `เช็คชื่อคลาส Claude AI`
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs`
3. ตั้งรหัสผู้ดูแลที่บรรทัด `const ADMIN_PIN = '';` เช่น `'2569'` แล้วกด 💾 บันทึก
4. **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - เลือกประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด **ทำให้ใช้งานได้** แล้วอนุญาตสิทธิ์ตามที่ Google ถาม (ถ้าขึ้นคำเตือนให้กด "ขั้นสูง → ไปที่โปรเจกต์")
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

ระบบจะสร้างแผ่นงานให้เองตอนใช้งานครั้งแรก:

| แผ่นงาน | เก็บอะไร |
|---|---|
| รายชื่อ | id, ลำดับ, ชื่อ-นามสกุล, ชื่อเล่น, รหัส, บริษัท/หน่วยงาน, อีเมล, เบอร์โทร |
| เช็คอิน | วันที่, ชื่อ, บริษัท, **เวลาเช็คอิน**, ตรงเวลา/สาย, ชื่อที่ขอแก้, ลายเซ็น |
| ตั้งค่า | ชื่อคลาส, เวลาเริ่มเรียน, บังคับเซ็นชื่อหรือไม่ |

> อยากเห็นลายเซ็นเป็นรูปในชีต: ตั้ง `SAVE_SIGNATURE_IMAGES = true` ใน `Code.gs`
> (รูปจะเก็บในโฟลเดอร์ Google Drive และแชร์แบบ "ทุกคนที่มีลิงก์ดูได้")

> แก้ `Code.gs` ภายหลังต้อง **Deploy ใหม่**: จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: ใหม่ → ทำให้ใช้งานได้ (URL เดิม)

## ขั้นที่ 3 — ขึ้น GitHub และเปิด GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `claude-checkin`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (โฟลเดอร์ `private/` จะถูกข้ามเพราะอยู่ใน `.gitignore`)
   ```bash
   git init
   git add .
   git commit -m "เว็บเช็คชื่อคลาส Claude AI"
   git branch -M main
   git remote add origin https://github.com/<ชื่อบัญชี>/claude-checkin.git
   git push -u origin main
   ```
   ถ้าอัปโหลดผ่านหน้าเว็บ GitHub (Add file → Upload files) **อย่าลากโฟลเดอร์ `private/` ขึ้นไป**
3. ไปที่ **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main` / `(root)` → Save
4. รอประมาณ 1 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/claude-checkin/`

## ขั้นที่ 4 — นำเข้ารายชื่อ

1. เปิดเว็บ → กด **"สำหรับผู้ดูแล"** ท้ายหน้า → ใส่ `ADMIN_PIN`
2. กด **นำเข้า** แล้วเลือก `private/attendees-claude-ai.csv` (หรือไฟล์ Excel/CSV ของคุณเอง)
3. รายชื่อจะถูกบันทึกลงแผ่นงาน **รายชื่อ** และขึ้นในทุกเครื่องภายใน 15 วินาที

## วิธีใช้วันเรียน

- **ผู้เข้าเรียน:** พิมพ์ชื่อ → กด **เช็คอิน** → เซ็นชื่อ → **ยืนยันการเข้าเรียน** → จะเห็นหน้า "เช็คอินสำเร็จ" พร้อมเวลา
- **ชื่อสะกดผิด:** ตอนเช็คอินกด "ชื่อสะกดผิด? แจ้งชื่อที่ถูกต้อง" ผู้ดูแลจะเห็นตัวกรอง **ขอแก้ชื่อ** แล้วกด "ใช้ชื่อนี้"
- **ผู้ดูแล:** แก้ชื่อ (ไอคอนดินสอ), ยกเลิกเช็คอิน, ตั้งเวลาเริ่มเรียน, เลือกวันที่ของรอบเรียน, ส่งออก CSV, คัดลอกไปวางใน Sheets
- **เน็ตหลุด:** ข้อมูลเก็บไว้ในเครื่องก่อน แล้วส่งเข้า Google Sheets ให้เองเมื่อต่อได้

## ข้อควรรู้

- repository แบบ **Public** ใครก็เปิดอ่านไฟล์ได้ อย่าใส่รายชื่อจริงหรือรหัสผ่านไว้ในไฟล์ที่ขึ้น GitHub — รายชื่อเก็บใน Google Sheet อย่างเดียว
- URL ของ Apps Script อยู่ใน `config.js` ซึ่งเปิดอ่านได้ ใครมี URL ก็ส่งการเช็คอินได้ แต่การแก้รายชื่อ/ตั้งค่า/ยกเลิกเช็คอินต้องใช้ `ADMIN_PIN`
- รหัสผู้ดูแลเป็นการป้องกันระดับพื้นฐาน ไม่ใช่ระบบล็อกอินเต็มรูปแบบ ไม่ควรเก็บข้อมูลอ่อนไหว (เลขบัตรประชาชน ฯลฯ)
- Google Apps Script รองรับคนเช็คอินพร้อมกันได้สบายสำหรับคลาสขนาดหลักสิบถึงร้อยคน
